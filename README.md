# NumericalMethods

by Milan Klöwer, based on materials originally taught by David Marshall, Andrew McRae and Andrew Wells.

in `/notebooks` the `.jl` files are [Pluto](https://plutojl.org/) notebooks, open them in Julia on a Pluto server (`import Pluto; Pluto.run()`).
The `.html` files don't render in GitHub, download and open in any browser to see a static HTML of the notebook.
